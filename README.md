# Music Quiz Pro

Музыкальная викторина для компании: рок, поп, микс и свои MP3, до 4 игроков или команд. Работает на компьютере, смартфоне и Android TV (управление пультом).

- `web/index.html` — сама игра, один файл. Его можно открыть в любом браузере.
- `app/` — Android-обёртка (WebView), которая упаковывает игру в APK.

## Как получить APK

Каждый push в `main` запускает GitHub Actions (вкладка **Actions → Build APK**). Готовый `MusicQuizPro.apk` появляется в разделе **Releases** и во вложениях запуска. Сборку можно запустить и вручную кнопкой **Run workflow**.

APK подписан ключом из репозитория (`app/musicquiz.keystore`), поэтому новые версии ставятся поверх старых. Для публикации в Google Play замените ключ на свой и храните пароли в секретах репозитория.
